# Defector-responsive strategy switching

This repository contains the manuscript, source code, numerical data, and figures for:

> Aarush Gunjal, "Analytical and Finite-Population Properties of Defector-Responsive Strategy Switching."

Status: manuscript prepared for submission as a BIOMATH Research Communication. It has not yet been peer reviewed or accepted.

## Overview

The project studies constant and defector-responsive switching from unconditional cooperation (ALLC) to Tit-for-Tat (TFT) in a three-strategy repeated Prisoner's Dilemma model that also contains unconditional defection (ALLD).

Pal, Lambert, and Nowak introduced the defector-proportional response in Supplementary Figure S8 of their 2025 paper. This project does not claim that response rule as a new mechanism. Its contributions are:

1. An exact break-even readiness-cost result for general benefit and cooperation-cost parameters.
2. Explicit existence and ALLD-invasion conditions for the relevant boundary equilibria.
3. A corrected finite-population Moran implementation that maps continuous switching intensities to probabilities with `1 - exp(-lambda)`.
4. Separate measurements of rescue probability, composition at rescue, and composition after a fixed post-rescue interval.

## Reproducing the results

Python 3.11 or newer is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python revised_analysis.py
```

The full run uses 1,000 independent Moran trials per parameter value and fixed random seeds. A faster development run is available with:

```bash
python revised_analysis.py --quick
```

To rebuild the paper after regenerating the figures:

```bash
pdflatex main.tex
pdflatex main.tex
```

## Core analytical result

For benefit `b`, cooperation cost `c`, and constant switching intensity `mu0`, the break-even readiness cost is

```text
k_star(mu0) = sqrt((b - c) * mu0 / 2).
```

This comparison is subject to the existence and invasion-stability conditions stated and proved in the manuscript.

## Reproducibility notes

- The deterministic solver uses SciPy's DOP853 method with strict error tolerances.
- Every deterministic terminal state is checked against the population simplex.
- Finite-population fitness is positive because payoff is mapped with an exponential function.
- A continuous switching intensity is converted to a per-update probability before sampling.
- Rescued populations are observed for `50N` additional updates.
- No clipping or post-integration renormalization is used.
